# Js

## Add behaviour through data-* attributes and event delegation
Add interactivity as `data-*` attributes handled by the delegated listeners in `resources/js/admin/*.js`, not per-page scripts or a frontend framework. Read user-facing text with `__t('key')` from `lang/{en,ms}/js.php`; never hardcode it.
